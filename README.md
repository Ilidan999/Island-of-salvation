## 🚀 Как запустить

Для запуска работ вам понадобится установленный интерпретатор **Python 3**.

1. **Клонируйте репозиторий:**
```bash
git clone git@github.com:Ilidan999/Island-of-salvation.git
```

2. **Перейдите в папку проекта:**
```bash
cd Island-of-salvation
```

3. **Настройка окружения (Рекомендуется)**

Чтобы избежать конфликтов библиотек, советуем использовать виртуальное окружение:

**Для Windows**
```bash
python -m venv venv
.\venv\Scripts\activate
```

**Для macOS / Linux** 
```bash
python3 -m venv venv
source venv/bin/activate
```
\+ Установка зависимостей (зависит от лабораторной).
4. **Запуск**

Запустите Jupyter Notebook:
```bash
jupyter notebook
```
После этого в браузере откроется веб-интерфейс. Перейдите в нужную папку (например, Integration/Serega) и откройте файл с расширением .ipynb.
